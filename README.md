# Каталог пісень

Публічний каталог, реєстрація, вхід і форма додавання пісні для авторизованих користувачів. Після входу відкривається сторінка, яку користувач намагався відвідати.

## Запуск

1. Запустіть бекенд Django на `http://127.0.0.1:8000` за його README.
2. У корені репозиторію фронтенду запустіть:

   ```bash
   python3 -m http.server 5500
   ```

3. Відкрийте [каталог](http://127.0.0.1:5500/). Для додавання пісні в базі має бути виконавець. Якщо список виконавців порожній, створіть запис через `POST /api/artists/` з access-токеном і тілом `{"name":"Назва виконавця"}`.

Токени зберігаються у `sessionStorage`. Якщо захищений запит повертає `401`, фронтенд отримує новий access через refresh і повторює запит один раз. Після завершення сеансу потрібно увійти знову. Кнопка «Вийти» видаляє обидва токени.
