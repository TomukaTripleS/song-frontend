# Каталог пісень — фронтенд

Проста сторінка на HTML, CSS та JavaScript. Отримує список пісень із Django REST API через `fetch` і показує назву, виконавця, жанр та посилання для прослуховування. Є кнопка оновлення, повідомлення про порожній список і помилки.

## Як запустити проєкт

Потрібен Python 3. Спочатку запустіть бекенд за інструкцією в [його репозиторії](https://github.com/TomukaTripleS/song). Потім у папці цього репозиторію:

```bash
python -m http.server 5500 --bind 127.0.0.1
```

Відкрийте **http://127.0.0.1:5500** у браузері. Не відкривайте HTML через `file://`.

- Фронтенд: `http://127.0.0.1:5500`.
- Бекенд: `http://127.0.0.1:8000`.
- Запит: `GET http://127.0.0.1:8000/api/songs/`.

Адреса API записана в `API_URL` у `app.js`. Бекенд дозволяє CORS для `http://127.0.0.1:5500` і `http://localhost:5500`. Якщо порт зміниться, оновіть `CORS_ALLOWED_ORIGINS` у налаштуваннях бекенду.

Щоб побачити пісні, спочатку створіть виконавця та пісню через Postman-колекцію бекенду. Фронтенд лише демонструє читання даних, решта CRUD доступна через API.
